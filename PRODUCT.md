# Product

## Register

product

## Users

Photographers and image makers working with RAW, JPG, or HEIC files on desktop and mobile. They want a capable editor that is quick to open, keeps original files private, and makes long local processing steps easy to understand.

## Product Purpose

Open Raw Editor provides an entirely browser-based workflow for opening, adjusting, and exporting photographs without uploading them. Success means users can move confidently from file selection to a faithful preview and full-resolution export while always understanding the app's current state.

## Brand Personality

Focused, capable, and calm. The interface should feel like a dependable photographic tool: compact, direct, and technically precise without becoming cryptic.

## Anti-references

Avoid decorative dashboard patterns, attention-seeking motion, glossy effects, and generic SaaS styling. Do not obscure the photograph with unnecessary interface chrome or leave users guessing during expensive local processing.

## Design Principles

1. Keep the photograph primary and the controls compact.
2. Make every long-running operation visible and clearly named.
3. Preserve user confidence with immediate feedback, stable layout, and explicit errors.
4. Use one consistent interaction language across desktop, touch, and installed-app entry points.
5. Expose technical detail only when it helps a photographer make or verify a decision.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Important states must not rely on color alone, touch targets should remain usable with coarse pointers, status updates should be announced to assistive technology, and motion should respect the user's reduced-motion preference.
